kfold: object-selection conditions for Kbuild Makefiles

kfold computes, for every object that a Kbuild tree can build, the configuration condition under which Kbuild builds it. It executes Kbuild Makefiles symbolically with a guard on every word of every variable, merges conditional branches into one state, and follows directories, composite objects, included fragments, host programs, and rule prerequisites. On Linux v6.6, its predictions match the objects of real builds exactly for tinyconfig, defconfig, a Debian configuration, and allmodconfig.

    Submitted Makefiles are analyzed in a sandbox: $(shell ...) expands to nothing and include cannot leave the submitted file's directory.

    Conditions range over option values y, m, and undef (unset). An m alternative also requires CONFIG_MODULES=y. Conditions describe Kbuild's selection only: they do not include Kconfig's depends on and select rules, so a satisfying assignment must still pass make olddefconfig. Object kinds: target (listed in obj-y, lib-y, …), member (of a composite such as ext2-y), program (object of a host or user program), rule (built as a rule prerequisite, e.g. the boot image and vDSO), extra (final link).
